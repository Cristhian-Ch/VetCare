## Descripción del Proyecto
VetCare es una plataforma desarrollada para la gestión integral de una clínica veterinaria. 
El sistema abarca los siguientes módulos principales:
* Agendamiento de citas.
* Registro de mascotas.
* Gestión de historial clínico.
* Sistema de notificaciones.
* Procesamiento de pagos.

## Arquitectura
El Backend/API VetCare está diseñado bajo una arquitectura de monolito modular.
